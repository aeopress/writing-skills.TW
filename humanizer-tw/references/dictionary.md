## 書面語 → 口語

### 書面代詞

| 避免 | 改用 |
|------|------|
| 其 | 它的、他的 |
| 該 | 這個、那個 |
| 此 | 這、這個 |
| 予以 | 給、進行 |
| 之 | 的（或省略） |

### 介詞結構

| 避免 | 改用 |
|------|------|
| 對於...而言 | 對...來說（或省略） |
| 就...來說 | 說到...（或省略） |
| 在...方面 | ...上（或省略） |
| 基於...的考量 | 考慮到... |
| 鑑於...的情況 | 因為... |

### 公告／官腔套話

公文、通知、公告常見的官腔冗詞。**即使是正式文體也要去**——正式 ≠ 官腔。

| 避免 | 改用 |
|------|------|
| 有關...事宜 | 關於...（或省略「事宜」） |
| 以免造成不便 | 刪除（空話） |
| 另行通知 | 再通知、另外通知 |
| 相應的／相應 | 對應的、適當的（或省略） |
| 此乃 | 這是 |
| 設備之檢查（書面「之」） | 設備的檢查（「之」改「的」，除非成語如三分之一） |
| 其影響／其效果（書面代詞「其」） | 它的影響、這影響（或省略「其」） |

### 動詞結構

| 避免 | 改用 |
|------|------|
| 進行了...的工作 | 做了... |
| 開展了...活動 | 辦了... |
| 實現了...的目標 | 達成... |
| 取得了...的成果 | 有了... |
| 做出了...的貢獻 | 幫了... |

## 絕對詞軟化

| 避免 | 改用 |
|------|------|
| 總是 | 常常、通常 |
| 從不 | 很少、幾乎不 |
| 每個人 | 很多人、大部分人 |
| 沒有人 | 很少人 |
| 一定會 | 可能會、應該會 |
| 絕對不會 | 不太會 |

> **技術／規格語境例外：** 「所有」「每個」「全部」在技術精確陳述中是**正確的**，不要軟化。例如「涵蓋**所有**邊界情況」「**所有** API 端點都需驗證」「**每個** request 都記錄」——這些是規格而非誇飾，改成「大部分」反而錯誤。只有**情感/誇飾**用法（「**所有**人都愛」）才軟化。

### AI 高頻強調詞

刪除或減少使用：

- 深深地、真正地、從根本上、本質上
- 簡單地、字面上、必然地、確確實實
- 實際上、事實上、嚴格來說

## 不要替換（假陽性防護）

去 AI 痕跡最常見的錯誤是**過度矯正**——把下列合法台灣用語也改掉。這些詞**看到也不要動**；錯改比漏改更傷文意。

| 合法詞 | 為何保留 | 不要改成 |
|--------|----------|----------|
| 優化 | 台灣科技業標準用語 | 最佳化（兩者皆可，但不必硬換，更不可換「調整」） |
| 最佳化 | 台灣標準用語 | 保留原樣 |
| 實現 | 「實現目標／夢想」台灣日常 | 完成、達成（語意會偏移，勿動） |
| 確保 | 正當動詞 | 保留原樣 |
| 整合 | 台灣商業/科技標準 | 保留原樣 |
| 互動 | 台灣標準（「交互」才是中國用語） | 用起來、操作（勿動） |
| 平台 | 台灣標準用語 | 保留原樣 |
| 框架 | 台灣科技業標準（framework） | 保留原樣 |
| 方案 | 台灣也說「方案」 | 保留（「解決方案」整體屬黑話另行處理） |
| 能力 | 通用名詞，無地域差異 | 保留原樣 |
| 涉及 | 書面語但非中國特有 | 保留原樣 |
| 打造 | 台灣行銷文案常用 | 保留原樣 |
| 支持（立場/情感） | 「支持你的決定」台灣標準 | 支援（僅軟體語境才改） |
| 項目（清單細項 item） | 「清單上三個項目」台灣合法 | 專案（僅 project 語境才改） |
| 質量（物理 mass） | 「恆星的質量」物理學名詞 | 品質（僅 quality 語境才改） |
| 所有／全部／每個（技術精確） | 「涵蓋所有邊界情況」是規格 | 大部分（僅誇飾語境才軟化） |
| 同時（實指並行） | 「一邊開會一邊回訊息，同時盯進度」 | 刪除（實指並行時勿刪） |
| 維度（實指 dimension／評分維度） | 「問卷分三個維度評分」「資料的維度」是實指清單或技術名詞 | 角度、方面（僅「從多個維度思考」這種空泛拔高才換） |
| 幼兒園 | 台灣法定名稱 | 保留原樣 |

**判準：** 一個詞是否該改，取決於**語境**而非字面。同形詞（項目/質量/支持/所有）只在特定語境才是中國用語或誇飾，其餘一律保留。拿不準時，**保留**。

## 快速對照

| 類型 | 例子 | 處理 |
|------|------|------|
| 商業術語 | 「賦能」「痛點」「底層邏輯」 | 用簡單詞替換 |
| 書面語 | 「予以」「該」「鑑於」 | 用口語替換 |
| 中國用語 | 「視頻」「默認」「數據」「營銷」「概率」 | 換成台灣說法 |
| 絕對詞 | 「總是」「所有人」（誇飾） | 軟化（技術精確語境不軟化） |
| **不要替換** | 「優化」「實現」「互動」「平台」「項目」 | **保留，勿誤殺** |
